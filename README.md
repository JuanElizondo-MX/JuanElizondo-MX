## Hola, soy Juan

**Full Stack Developer** con foco en Frontend

Vengo de ventas, y hace un par de años decidí meterme de lleno al desarrollo de software. Terminé el bootcamp de **Soy Henry** y desde entonces no he parado de construir cosas: me muevo cómodo en todo el stack (React, TypeScript, Node.js), aunque disfruto especialmente el lado del Frontend. Me gusta entender el problema completo, no solo la parte visual: cómo se conecta con la API, cómo se guardan los datos, qué pasa cuando algo falla.

Reynosa, Tamaulipas, México &nbsp;·&nbsp; Remoto / Híbrido / Presencial
